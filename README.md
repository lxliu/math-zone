# 幸运星计算乐园 🦊⭐

让小朋友**每天坚持**做计算练习的 H5 小游戏。做完当天的题就能收集 **幸运星**，
用星星去**解锁可爱动物图鉴**，把枯燥的口算变成“攒星星养动物”。

- 8 类计算题，家长自由配置每天题量
- 不限时间、不排名、不催促，孩子答完才结算
- iPad 上可“添加到主屏幕”，像 App 一样全屏、离线也能玩
- 数据只存在自家设备的浏览器里，支持多账号与备份导出/导入

## 打开就能玩

👉 直接访问：**https://lxliu.github.io/math-zone/**

家长不需要安装、部署或注册任何东西，用浏览器打开这个网址即可。
首次打开先建一个小朋友账号（姓名、性别、头像）；**建完账号会自动进入「题目配置」页**，
第一次进去**不需要密码**，跟着页面提示（改题量 → 点「保存并开始练习」）走一遍就能开始玩了。

### 加到主屏幕（iPhone / iPad / Android 都建议）

加到主屏幕后是全屏、无地址栏，而且**离线也能玩**，系统也不容易清理数据：

- **iPhone / iPad（Safari）**：打开网址 → 点「分享」→「添加到主屏幕」
- **Android（Chrome 等）**：打开网址 → 点菜单「⋮」→「添加到主屏幕 / 安装应用」

> 建议横屏使用（游戏按横屏设计）。

## 怎么玩（游戏规则）

1. 进入「今日」，点开始做题。
2. 用屏幕上的数字键盘输入答案。
3. **全部做对**，才能拿到当天的幸运星；**差一个也拿不到**。
4. 答错只会提示“再想想”，**不会直接给答案**，错题会让你重做，直到做对为止。
5. 结束时才显示总用时。计时全程隐藏，不给孩子压力。
6. **每天只有一次机会**，只能做当天，错过不补；中途退出会自动保存进度，回来接着做。

### 幸运星怎么来

- **每答对一题 = 2 颗幸运星**。
- 按默认配置每天每类 3 题，共 **8 类 × 3 = 24 题 = 48 颗星星**（家长可以改）。
- 当天没有全部做对，星星是 0，第二天重新开始。

## 账号、头像与数据

- **多账号**：可以给每个孩子建一个账号，各自独立记录星星、动物和进度。
- **头像**：初始可选小男孩 / 小女孩头像；**每解锁一只动物，就能把它设成头像**。
- **数据位置**：全部保存在本机浏览器里，不上传、不需要网络账号。
- **备份**：设置页有「导出备份 / 导入备份」，生成一个文件保存起来。换设备或清理浏览器前建议先导出。

## 常见问题

**换设备 / 清空浏览器后数据没了？**
数据只在本机。请用「设置 → 导出备份」在旧设备导出，再到新设备「导入备份」。

**iPad 上放几天不玩，进度会丢吗？**
Safari 对**没添加到主屏幕**的网站有“长期不访问可能清理本地数据”的策略。所以强烈建议
**添加到主屏幕**后从图标进入，并养成定期「导出备份」的习惯。

**没有网络能玩吗？**
添加到主屏幕后，已缓存的页面可以离线打开；3D 动物模型在首次解锁时会联网加载，之后也能离线看。

**孩子乱改题量怎么办？**
家长设置需要密码才能进，改完必须点保存；孩子日常看不到这个入口。

**题目会不会太难 / 太简单？**
每类题都是“题型固定、数字随机”，由程序现场出题。家长按孩子的水平调整每类题量即可，
不会的类别可以设成 0。
